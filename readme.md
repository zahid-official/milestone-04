## Overview

This repository contains five JavaScript functions that solve different logic-based problems from a structured challenge brief. Each solution follows the required function signature and focuses on returning the correct output for both normal and edge-case inputs.

The goal of this repo is to showcase problem-solving ability through practical coding tasks, not just syntax usage. It reflects step-by-step thinking, defensive programming, and the ability to translate problem statements into working solutions.


## Highlights

- Pure JavaScript solutions with no external dependencies
- Five standalone problems solved in a single script
- Validation-focused logic for handling edge cases
- Covers strings, arrays, objects, conditionals, and calculations
- Written to match exact function signatures and return requirements

## Problems Solved

| Problem | Function | What It Solves |
| --- | --- | --- |
| Tax Calculator | `calculateTax(income, expenses)` | Calculates tax from income and expenses while rejecting invalid numeric input |
| Notification Generator | `sendNotification(email)` | Extracts username and domain from an email and builds a formatted notification message |
| Digit Checker in Name | `checkDigitsInName(name)` | Detects whether a name contains numeric characters |
| Admission Final Score Evaluator | `calculateFinalScore(obj)` | Computes eligibility from test score, school grade, and family condition data |
| Waiting Time Predictor | `waitingTime(waitingTimes, serialNumber)` | Estimates remaining waiting time from previous interview durations and serial position |
